# Euler-Based Simulated Likelihood for Multidimensional Diffusions

This repository contains a mathematical manuscript, reproducible numerical experiments, and the
figures and tables they generate.

## Layout

```text
paper/                  manuscript and everything it includes
  main.tex              LaTeX source
  main.pdf              compiled manuscript
  references.bib        bibliography
  figures/              vector PDF and PNG figures (generated)
  tables/               CSV and LaTeX tables (generated)
code/
  generate_results.py        figures and tables
  check_correlation_matrix.py  Brownian correlation-matrix audit
  argmax_counterexample.py     the argmax investigation
  verify_reproducibility.py    regeneration check used by `make verify`
  make_release.py              release artefacts under dist/
tests/                  pytest suite for every analytical formula
docs/
  repository_audit.md              build and reproducibility baseline
  bibliography_audit.md            every reference checked against primary sources
  adversarial_mathematical_review.md  verification table and open items
notes/
  argmax_counterexample.md  the argmax investigation and its go/no-go conclusion
reference/              literature under review; local only, never committed
dist/                   release artefacts; gitignored
```

Everything under `paper/figures` and `paper/tables` is generated by `code/generate_results.py`.
Edit the script, not those files.

## Reproduce the numerical results

```bash
python code/generate_results.py
```

The script uses a fixed random seed and no external data.

## Build the manuscript

The document uses `biblatex` with the `biber` backend, and is compiled from inside `paper/` so
that the relative `figures/` and `tables/` paths resolve.

```bash
make          # figures and tables, then the PDF
make figures  # regenerate figures and tables only
make pdf      # rebuild the PDF only (alias: make paper)
make verify   # check that committed figures and tables regenerate exactly
make test     # run the pytest suite
make check    # test, then verify
make clean    # remove LaTeX auxiliary files, keep main.pdf
```

`make verify` regenerates every artefact into a scratch directory and compares it with the
committed copy. Figure output carries no embedded timestamp, so the comparison is exact.

The build uses `latexmk`, which runs `pdflatex`, `biber` and the reruns in the right order. To
compile by hand instead, run the cycle from inside `paper/` and let each pass finish:

```bash
cd paper
pdflatex -interaction=nonstopmode main.tex
biber main
pdflatex -interaction=nonstopmode main.tex
pdflatex -interaction=nonstopmode main.tex
```

## Scope

The manuscript establishes an exact Brownian counterexample, derives dimension-dependent moment
and central-limit rates for the endpoint estimator, records that the implemented simulation
design does not satisfy the published rate conditions, and analyses the mathematical status of
the four-dimensional exchange-rate application. It does not claim that the published
finite-sample empirical estimates are necessarily incorrect.
